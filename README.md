# grimoire-addons

Personal Grimoire add-on index for [snachodog](https://github.com/snachodog).

`index.json` at the repo root follows the same format as the official
[`grimoire-codex/community-add-ons`](https://github.com/grimoire-codex/community-add-ons)
index, so it can be added directly as a custom index URL in Grimoire:

**Settings → Add-ons → Index URL** →
`https://raw.githubusercontent.com/snachodog/grimoire-addons/main/index.json`

## Add-ons

| Add-on | Target | Source |
| --- | --- | --- |
| [Paizo Product Code](scrapers/paizo-product-code/) | book | store.paizo.com |

See each add-on's own README for what it fills in, what it deliberately
leaves unmapped, and why.
